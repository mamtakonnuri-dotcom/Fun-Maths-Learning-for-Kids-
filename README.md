# Fun Maths Learning

A simple free/open-source educational website for primary students.

## Included
- Class/level selection
- Multiplication quiz
- Division quiz
- Equal Groups
- Fair Sharing
- Multiplication Race
- Missing Number
- Score and feedback

## Run
Open `index.html` in a web browser. No installation or internet connection is required after the files are downloaded.

You can edit `index.html`, `style.css`, and `script.js` to change the content, design, questions, or games.
